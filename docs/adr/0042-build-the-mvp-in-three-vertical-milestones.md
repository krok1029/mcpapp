# 以 Define、Deliver、Trace 三階段完成 MVP

最終 MVP 內容不刪減，但依序交付三個可獨立展示的內部 Milestone：M0 Define 完成訪談、結構化 Spec、UI 編輯與核准、SQLite Revision 及 Resume，並以 `basic-host` 驗證本機 UI；M1 Deliver 完成 Repository Plan、GitHub Provisioning、Backlog、Ticket、驗證、多 Commit、Review、CI、PR 與 Merge，並以 Codex 驗證完整 Agent 執行；M2 Trace 完成開發證據鏈、File-level Knowledge Graph、相關子圖、Impact Analysis 與 Project Record Bundle。M0 依 ADR-0057 僅驗證本機路徑；ChatGPT Pro 的 Secure MCP Tunnel 路徑延至 M0 完成且遠端授權重新決策後開始。每階段都必須保持可執行與可驗證。
