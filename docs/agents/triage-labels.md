# Triage Labels

Skills 使用五種標準分流角色。此表定義各角色在本專案所使用的實際標籤。

| 標準角色          | 本專案標籤        | 意義                           |
| ----------------- | ----------------- | ------------------------------ |
| `needs-triage`    | `needs-triage`    | 等待維護者評估                 |
| `needs-info`      | `needs-info`      | 等待回報者補充資訊             |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由 AI Agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要由人類處理                 |
| `wontfix`         | `wontfix`         | 不會進一步處理                 |

當 skill 提及標準分流角色時，使用此表對應的本專案標籤。
